## 6. 服务化

```
$ launchctl print gui/$(id -u)/com.ruic.goofishhunter | grep state
	state = running
$ ps aux | grep "Microsoft Edge" | grep -c -- "--headless"
1
$ curl -s http://127.0.0.1:7801/api/health
{"ok":true,"version":"0.1.0","headless":true,...}
```

- 登录即启动，进程退出自动拉起（`RunAtLoad` + `KeepAlive`）。
- 自动扫描无窗口；只有「打开登录窗口」会弹出浏览器。
- 同一账号的浏览器 profile 加了跨进程文件锁：第二个进程会得到
  「浏览器正被另一个进程占用」的明确提示，而不是莫名的启动失败。
